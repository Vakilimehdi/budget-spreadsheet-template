# قالب صفحه‌گسترده بودجه | Monthly Budget Spreadsheet Template

## فارسی

یک فایل اکسل آماده برای مدیریت بودجهٔ ماهانهٔ شخصی — درآمد و هزینه‌ها را ثبت کنید، بقیه‌اش خودکار حساب می‌شود.

> **نسخهٔ نمایشی (دمو):** فایلی که در این ریپو می‌بینید نسخهٔ دموی قالب است — فقط تراکنش‌های نمونهٔ ژانویه را دارد تا ساختار و فرمول‌ها را ببینید. نسخهٔ کامل (خلاصهٔ ۱۲ ماهه و برگهٔ بودجهٔ کامل) فقط بعد از پرداخت ارسال می‌شود.

### برگه‌ها (Sheets)

- **Dashboard** — جمع کل درآمد، جمع کل هزینه‌ها، مانده و نرخ پس‌انداز؛ جدول ماهانهٔ ۱۲ ماهه با فرمول؛ نمودار ستونی درآمد در برابر هزینه
- **Transactions** — جدول تراکنش‌ها با ردیف‌های نمونه (قابل حذف): تاریخ، دسته، توضیح، نوع (درآمد/هزینه)، مبلغ. اعتبارسنجی داده برای نوع و دسته فعال است
- **Budget** — بودجهٔ ماهانه برای هر دسته + ستون «واقعی» که با تغییر ماه (سلول B3) برای همان ماه حساب می‌شود؛ ستون «باقی‌مانده» هم خودکار است
- **How to use** — راهنمای قدم‌به‌قدم استفاده

### همه‌چیز با فرمول است

هیچ عددی دستی در داشبورد و خلاصهٔ ماهانه نیست — همه با `SUMIF` و `SUMIFS` از برگهٔ تراکنش‌ها حساب می‌شوند. فقط تراکنش‌های خودتان را اضافه کنید.

## English

A ready-made Excel file for personal monthly budgeting — log income and expenses, everything else calculates itself.

> **Demo version:** the file in this repo is the demo of the template — it contains January example transactions only, so you can see the structure and formulas. The full version (complete 12-month summary and Budget sheet) is sent only after payment.

### Sheets

- **Dashboard** — total income, total expenses, balance and savings rate; a 12-month summary table with formulas; an income-vs-expenses bar chart
- **Transactions** — a table with example rows (delete them): date, category, description, type (Income/Expense), amount. Data validation is on for type and category
- **Budget** — monthly budget per category plus an "Actual" column that recalculates for the month you set in cell B3; "Remaining" is automatic
- **How to use** — step-by-step instructions

### Everything is formulas

No hand-typed numbers in the dashboard or monthly summary — everything is `SUMIF` / `SUMIFS` over the Transactions sheet. Just add your own transactions.

### Compatible with

Microsoft Excel, LibreOffice Calc and Google Sheets (import the file into Sheets).
